## Функціональність

### Захист доступу
- Тільки користувачі з роллю `ADMIN` можуть отримати доступ до адмін панелі
- Неавторизовані користувачі перенаправляються на сторінку входу
- Користувачі без адмін прав перенаправляються на головну сторінку

### Форма створення машини
Форма містить всі необхідні поля:

**Основна інформація:**
- Назва (name)
- Бренд (brand) 
- Модель (model)
- Ціна за день (price)
- Рейтинг (rating)

**Технічні характеристики:**
- Тип палива (fuelType)
- Коробка передач (transmission)
- Пробіг (mileage)
- Об'єм двигуна (engineSize)
- Потужність (enginePower)
- Максимальна швидкість (topSpeed)
- Розгін 0-100 км/год (acceleration)

**Додатково:**
- Зображення (до 10 файлів)
- Функції та особливості (динамічний список)

### Валідація
- Використовується React Hook Form з Zod схемою
- Всі поля валідуються на клієнті
- Показуються детальні повідомлення про помилки

### FormData
Дані надсилаються в форматі FormData, як показано в скріншоті:
- Основні поля як текст/числа
- Деталі машини як `carDetails[fieldName]`
- Зображення як масив файлів
- Функції як масив строк

## Як використовувати

### 1. Увійти як адміністратор
- Переконайтесь, що ваш користувач має роль `ADMIN` в базі даних
- Увійдіть в систему

### 2. Відкрити адмін панель
- Клікніть на аватар користувача в хедері
- Виберіть "Admin Panel" з випадаючого меню
- Або перейдіть прямо на `/admin`

### 3. Створити машину
- В адмін панелі виберіть "Створити машину"
- Заповніть всі обов'язкові поля
- Завантажте мінімум одне зображення
- Додайте мінімум одну функцію
- Натисніть "Створити машину"

### 4. Перевірити результат
- При успішному створенні з'явиться toast повідомлення
- Дані будуть відправлені на backend як FormData
- Список машин автоматично оновиться

## Технічні деталі

### Використані технології
- **React Hook Form** - управління формою
- **Zod** - валідація даних
- **TanStack Query** - управління станом API
- **React Hot Toast** - повідомлення користувачу
- **FormData** - відправка файлів

### API ендпоінт
```
POST /cars/create
Content-Type: multipart/form-data
Authorization: Bearer {token}
```

### Структура FormData
